CONTROLE DE DÍVIDAS — PRO V3 / RENDER

1. Substitua no GitHub os arquivos antigos pelos arquivos deste pacote.
2. Faça commit/push.
3. No Render mantenha:
   Build Command: npm install
   Start Command: npm start
4. Environment:
   NODE_VERSION = 22.16.0
   NODE_ENV = production
   ADMIN_USER = admin
   ADMIN_PASSWORD = sua senha inicial
   SESSION_SECRET = chave aleatória com 32+ caracteres
5. Vá em Manual Deploy.
6. Escolha "Clear build cache & deploy".
7. Abra o site. A versão V3 usa arquivos versionados e não mantém cache forte.

TROCA DE SENHA:
Minha conta > Alterar senha > informe a senha atual e a nova senha.
Ao salvar, a sessão é encerrada e você volta ao login. Entre usando a NOVA senha.

ATENÇÃO:
Em armazenamento efêmero do Render, deploy/restart pode apagar o SQLite local.
Para uso definitivo, conecte armazenamento persistente.
